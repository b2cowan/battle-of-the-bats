Lineups reads like Practice plans

The Lineups room now opens the way the Practice plans room does: the portal's underlined tab row, a Next game card on top carrying the page's one bright button, rows that are plain doors, and a Needs lineup count that counts only what is ahead. The League / Tournament / Scrimmage chips are gone by your ruling. The fastest way to fail this walk is to find anything on the Lineups page that the Practice plans page next to it would not do.

Route: UAT Test Team → Lineups, with Practice plans open in a second tab to compare against. Parts A–C on a desktop window; Part D at phone width.

Before you start: make sure the team has a game ahead of it. The fixture's games may all be in the past, and a room with nothing coming up shows no card and no count — honestly, but it gives you nothing to check. If Upcoming games is empty, go to Schedule and add a league game a few days out (any opponent, any time). One more, starting right now, gives Part B a live game to look at.

Part A

The room at a glance

Lineups, on the Games tab. Hold the Practice plans page beside it.

A1

The tabs are the portal's tab row, and each one is an address

The dark two-button pill is gone. Games · Templates now read as the same underlined row Practice plans, Money, Insights and Skills & Goals wear.

Verdict
A2

The Next game card

The nearest game ahead is the card, exactly as the nearest practice is on Practice plans: kicker, how far away it is, the date and time as the headline, the opponent and field beneath, the readiness chip on that line's right, and the page's one bright button.

Verdict
A3

The rows are doors, and the past reads as a record

The one bright button lives on the card; no row carries it. Above the band the room is a builder, below it a record — the same two vocabularies Practice plans uses.

Verdict
A4

Needs lineup counts what is ahead

The count used to include every game in the past that never got a lineup — a coach in September was told a game in May still needed one. It now counts upcoming games only, the fix Practice plans got for the same defect.

Verdict

Part B

Game day

Needs a game inside its live window — from two hours before it starts to three hours after it ends. A game added on the Schedule starting now is one.

B1

The live game is the card, and the console is its door

On Practice plans the card turns to Run practice inside the practice's window. Here it turns to the game-day console — even for a game that started an hour ago and would otherwise sit under Recent.

Verdict

Part C

Templates

The Templates tab. The list, rename, delete and apply are unchanged; where the create lives and where the editor lands you are not.

C1

New template is in the header, the hint line is gone

Every hub puts its one create in the page header. The bar above the list that held "Reusable base lineups…" beside the button is deleted; the empty state still teaches what a template is.

Verdict
C2

Writes

Verdict
C3

The editor comes back to Templates, and a tab switch closes a rename

Now that Templates is an address, the template editor can land on it instead of dropping you on the Games list.

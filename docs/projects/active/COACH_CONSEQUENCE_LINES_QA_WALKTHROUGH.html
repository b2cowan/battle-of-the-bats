Do the money screens tell the truth?

The record-money form used to promise what a save would do, in prose nothing could check. Three of those promises were wrong. The figures are now derived from the same code that moves the money and shown as chips; the sentence keeps only what a chip cannot say.

Where: any team → Money → Record (the button in the page header, beside Import). Every step below opens that one form.

⚠ This walk is the only ongoing coverage this surface has. The strip lives in a modal, and the automated layout check does not open modals — it will report this screen green forever. The unit tests hold the figures; nothing automated holds the rendering.

The refund — the reason all of this exists

This is the sentence that was wrong. It told you the budget line dropped and nobody was owed, and never mentioned that your cash went up.

Do: Record → Money back on something we paid → pick any item → amount 200.

Why that last one matters: the first build coloured by arrow, so a refund's line went red — danger styling for the best thing that had happened all week. Colour is now reserved for cash, the one figure with a stable good/bad reading.

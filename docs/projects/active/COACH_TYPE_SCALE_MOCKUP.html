What actually moved

  • Card titles 9.9px → 11px. The card's own name now leads the chip beside it. This single change does most of the work.
  • Page title 22.4px → 20px. Opens a clean step under the figure instead of a 10% near-tie.
  • Tab row 11.5px → 14px, sentence case. Navigation stops competing with column headings — see specimen B.
  • Masthead detail line 10.6px → 11px. It is text you read, so it leaves badge size.
  • Buttons unified at 14px. Record, Import, ghost and danger actions were 14.1 / 14.1 / 13.6 / 13.6.

Built 2026-08-28 — two things changed on the way in as-built

  • The masthead detail line landed at 11px, not the 12px drawn above. 12px overflowed the phone masthead by 3px, caught by the layout sweep. At phone width that line cannot wrap — only the club name may shrink, while the season and record are rigid by design — so the extra width had nowhere to go. 11px is the ladder's label step and is arguably its right home anyway: a dense strip of secondary facts. It is one value at every width. This frame is drawn at the as-built size.
  • The tab labels stayed Title Case ("Budget Plan", "Playing Time") rather than the sentence case drawn above. Removing the uppercase exposed a split the transform had been hiding — the tryout flow writes sentence case ("Tryout day", "Build team") while Money and Insights write Title Case. Normalising that is a copy change that also reaches foot links, rail links and help articles; doing half of it would leave one thing wearing two names. Logged as a follow-up rather than smuggled in here.

06 — The proposal

Seven steps, named for the job they do

Named for role, never for size — the same rule your ink ruling landed on in August, when one value turned out to mean both "meta text" and "hairline" and neither could move without the other.

The load-bearing property

The top four steps separate by size — gaps of 1.14× to 1.25×, all plainly visible. The bottom three separate by treatment — case, letter-spacing, weight and ink — and their size gaps are deliberately tiny.

That is the point, not a flaw to tidy up later. Below about 13 pixels a one-pixel step is invisible, so trying to build rank out of size down there is exactly what produced six values inside a three-pixel window in the first place.

Deliberately unchanged unchanged

  • Table column headings hold at 12px. They were raised on 15 August to fix a measured legibility defect. That ruling stands and is not being unwound here.
  • Badges and inline table actions stay at 10px. Glance tokens, decided 23 May. Untouched.
  • The figure stays the biggest thing on the card. It moves 0.8px and nobody will see it.
  • No layout, spacing, colour or card-height changes. Type assignment only.
07 — If you approve

Three phases, and only one of them is expensive

Phase 1 — clear the drift

55 places. Thirty of the 61 values are used five times or fewer. Each snaps to its nearest neighbour; every move is under half a pixel, so nothing visibly changes. Halves the value count for almost nothing.

Phase 2 — this mockup

About ten places. Card titles, page title, tab row, buttons, the masthead line. This is the part you actually noticed, and it can ship on its own.

Phase 3 — adopt the ladder later

1,157 places. Mechanical but genuinely expensive, and the only phase with real risk: type changes reflow tables, and reflowed tables overflow sideways. Best run after the coach money forms review, and not close to the tablet band that was only just settled.

Open this on the device you want to judge it on. Every size here is drawn 1:1 in pixels — a laptop at 125% display scaling, or a zoomed tab, will show you the wrong answer.

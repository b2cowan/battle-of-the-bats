A parent can name a child's friends at sign-up

On a club with League Plus or Club, each child's card on the house-league sign-up form now asks “Who would you like Maya to play with?” under the division line: up to the club's maximum, by name or by the other family's friend code. Each child gets a friend code, shown with Copy on the confirmation screen and on “Your sign-up”, and as text in the confirmation email. A family can change its requests on “Your sign-up” until that child's division has its teams made. The club sets the maximum (None, 1 or 2) on the season's Overview. Four walks, one purpose each. About 25 minutes.

What the registrar does with the requests (the Friend requests view) is Part 2; the draft keeping friends together is Part 3. Neither is in this walk.

Before you start

  • No script to run. Walks 2 to 4 make new test sign-ups; that is expected.
  • Walk the parts in order, 1 to 4. Walk 3 uses the sign-up you make in walk 2. Each walk opens with a stop check.
  • The drawings these screens were built to: tabs 1, 2 and 3 (top).

Already proved by tests and my own pass (don't re-do these)

  • The question is absent on every plan without friend requests (Tournament, Tournament Plus, League, a coach's team), whatever the season's setting says; the setting itself is refused there too.
  • Every child gets a code on sign-up, by every route a sign-up is made (the family's form, a staff add, a carry-over). The 404 sign-ups already on dev in live seasons were given one; all 404 pass the form's own typo check. Sign-ups in finished seasons got none.
  • The typo check catches about 98 in 100 single mistyped characters, with no lookup: nothing the form says tells a visitor whether a child or a code is registered.
  • The family's page and its Change answer only with what that family typed: never the name behind a code, never whether it matched.
  • The two privacy lines are word for word as /legal approved them. The names table is readable by the server alone.
  • Typecheck and lint are clean, plus the sign-up, link and family-page tests and two new friend test files.

Your time goes on judgment: does the question sit naturally in the child's card, is the code easy to find and pass on, and does each screen say only what the family needs?

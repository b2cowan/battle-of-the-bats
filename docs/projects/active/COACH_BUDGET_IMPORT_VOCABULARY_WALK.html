The words in the template

A budget import used to accept Tourney Fees without a word and quietly mint a second cost name beside Entry Fees — for the rest of the season. The Excel template now carries your whole vocabulary and offers it as dropdowns, and the preview stops a duplicate before it exists. Six parts. Everything you tick is saved in this browser; Copy findings at the top hands the lot back to a chat.

Pin your two words first

This walk is about vocabulary, so it must not assume yours. Open the template's Reference tab in Part A, pick any category with at least two cost names under it, and write them here. Everywhere below, KNOWN is that first cost name and HEADING is its category — the examples in each step show Entry Fees / Tournaments only as an illustration.

Part A

The file itself

Download the month grid template in Excel. Everything here is about the file on your disk — no importing yet.

A1

Three tabs, and the one you fill in is first

excel

Open the file. Along the bottom you should find Data (the grid you fill in) and Reference (the list). The third tab, Lists, is deliberately hidden — it feeds the dropdowns. Data should be the tab the file opens on.

If you're curious, right-click a tab → Unhide will show Lists. It's hidden, not locked away, on purpose: a coach who finds it should be able to look at it.

A2

Reference lists every word your team can use

the ask

Three columns: Category, Cost name, Where it comes from. That last one should read Standard, Your club or This team.

The question this step exists to answer: is anything missing? Compare it against the item picker on a budget line. Every word the picker offers on the expense side should be here — and nothing from the income side, because an imported row is always a cost.

A category with no cost names still gets a row, with the name column blank. That's intended — you should be able to see the heading exists.
A3

Not one dollar figure anywhere in the file

standing rule

Every amount cell blank, on every tab. The template says what to budget for; you say how much. A figure in a downloadable file is a figure the product proposed.

The month columns should be your season's own months where the team already has dated money, and a year from this month where it doesn't.

Part B

The dropdowns

The half you asked for by name. Do this twice — once in Excel, once after uploading the same file to Google Sheets — because the second one is where this kind of thing usually breaks.

B1

Category and Line both offer a list

the askexcel + sheets

Click any empty cell in column A or B — including a long way down, say row 200. A caret should appear, and opening it should list your categories in A and every cost name in B.

A · 200▾ your categories B · 200▾ every cost name
Column B is deliberately flat — it lists every cost name, not just the ones under whatever you picked in A. Making it follow column A needs Excel formula tricks that break on a category containing an & and break again in Google Sheets. Pairing a name with the wrong heading is caught in the preview instead — that's step D2.
B2

It offers — it never refuses

must not regress

Type something that is not on the list into column B — Charter Bus will do. Excel must accept it with no error popup.

This is load-bearing, not a nicety. A coach with a cost we have no word for has to be able to name it; that's the whole reason the importer creates one. A dropdown that refuses would make the feature worse than what it replaced.

B · typedCharter Bus → excelaccepted, no warning

Part C

The spelling that used to cost you a word

Fill the Data tab by hand for these — the dropdowns would defeat the purpose. Put HEADING in column A, the spelling under test in column B, and any amount in a month column. Then Import ▾ → Budget lines → Upload a file, and read the preview.

C1

A hyphen no longer invents a second word

the whole point

Type KNOWN with a hyphen in place of its space — Entry-Fees for Entry Fees. Before today this created a permanent new cost name.

you typeEntry-Fees → preview showsEntry Fees
Read the Line cell in the preview, not just the verdict. The correction has to be visible to you before you import. If the preview still says Entry-Fees but the import quietly files it under the old word, that's a liberty rather than a correction — and it's the one thing in this build I'd most want you to catch.

Try the same with a double space, a trailing full stop, and all-lowercase. All four should land on your library's own spelling.

C2

It imports onto the word you already had

no new item

Import that row. Then open any budget line's item picker and confirm there is still only one of KNOWN in the list — no hyphenated twin.

Then check the line on the Budget plan: it should read as KNOWN under HEADING, and Budget vs. Actual should show its spend on the existing row rather than a new one beneath it.

C3

A category typo stops blocking the row

side effect, welcome

Put HEADING in column A with a trailing full stop — Tournaments. — and a valid cost name in B. That row used to be refused outright with "No category called…".

A · you typeTournaments. → previewTournaments · Adds

Part D

Words we've never heard of

Three different situations, three different sentences. None of them blocks the row — a genuinely new cost still has to import in one pass.

D1

"Did you mean…", with a one-tap fix

the ask

Type KNOWN missing its last letter, or one letter wrong — Entry Fee for Entry Fees. Close, but genuinely a different word, so it is offered, never applied for you.

you typeEntry Fee → verdictAdds · New name — did you mean “Entry Fees”?

Tap Use “Entry Fees”. The Line cell should change and the warning should disappear as you watch. Then check the reverse: leave it alone, import, and confirm Entry Fee really does become a new word — because sometimes it genuinely is one.

D2

The right word under the wrong heading

catches B1's flat list

Put KNOWN in column B but a different category in column A. This is what the flat dropdown makes easy, so it's the case the preview has to handle well.

AOfficials BEntry Fees → verdict“Entry Fees” is already under Tournaments — this adds a second one under Officials.

The fix button here should offer the heading, not a spelling. Tap it and the Category dropdown should move.

D3

Something genuinely new says so, plainly

must still work

Type a cost nothing in your list resembles — Charter Bus, Ferry Crossing. No suggestion should be offered, because a guess here would be worse than silence.

you typeCharter Bus → verdictAdds · New name — adds “Charter Bus” to your Tournaments list.

Import it, then confirm it is in the item picker afterwards. That path was always there and must stay — the change is that you were told.

Part E

Nothing else moved

The regressions. E1 is the one that would cost the most if it broke, and it is invisible from inside the app.

E1

A template you downloaded last week still imports

silent if broken

The fill-in sheet was renamed from Template to Data so the two new tabs can never be mistaken for the grid. Files already on people's machines still say Template.

If you have an older download, import it. If not, take the new file, delete the Reference and Lists tabs, rename Data to Template, and import that. It must behave exactly as before.

E2

CSV still downloads, and still imports

accepted tradeoff

A CSV can't carry a tab or a dropdown, so it is unchanged: headings and a few example rows. The note above the buttons should say so rather than leaving you to discover it.

Fill one in and import it. Everything in Parts C and D should behave identically — that's the half that protects a coach whatever their sheet came from.

E3

Bills, paste, and the export round trip

untouched, allegedly

Three quick ones:

Bills schedule — its template should have a Category dropdown but no Line dropdown, because a bill's description is genuinely free text. Paste — paste rows straight into the box instead of uploading; Parts C and D should read the same. Round trip — export the Budget plan, change an amount, import it back.

Part F

Three I'm not sure about

Not checks. Answer them in the notes and they'll come back with your findings.

Is a corrected spelling enough of a telling?

When Entry-Fees becomes Entry Fees, the only signal is that the cell now reads differently. There's no sentence saying "matched to your existing wording". I left it silent because a warning on something we're confident about is noise — but a coach who typed the hyphen deliberately might not notice we overruled them.

Is a flat list of sixty cost names actually useful?

Column B offers every word your team has, regardless of the category in column A. It kills the typo, which was the ask. But sixty entries in one dropdown may be worse to scan than typing — and it invites exactly the mismatch D2 exists to catch. The alternative is no dropdown on that column at all, leaving the Reference tab to do the teaching.

Does the CSV need something after all?

CSV users get the preview's protection but none of the vocabulary. The only way to give a CSV the list is to write every category and cost name into it as blank rows — which reads as the product proposing a sixty-line budget, and fills the preview with skipped rows. I chose not to. Say if that's wrong.

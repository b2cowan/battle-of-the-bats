The plan file reads back whole

Download your season budget plan, then import that same file. Every line should come back as a change to itself — costs to your cost lines, money in to your money-in lines — with nothing added, nothing dropped and nothing refused.

This walk exists because §158's step C2 described one known gap: money-in lines re-importing as new costs. Building the fix turned up two more breaks in the same file, both older and both worse, and neither visible to any gate. This walk checks all three at once — and the fastest way to fail it is to find anything in the preview that is not the word Updates.

Route: UAT Test Team → Money → Budget. Every step is Export then Import on that one tab. Only the last part commits anything; everything before it ends on Cancel.

Cancel every preview until Part D. If you commit one by accident the plan gains duplicate lines and the later steps stop meaning anything — say so in the notes and stop rather than carrying on.
What to hold on to — the shape, not the digits. This team's plan has cost lines under real categories, and money-in lines under Fundraising, Tournaments and Other Income. Before you start, note two things off the Budget tab: how many lines the plan has, and the two tile figures Planned costs and Planned funding. Every preview in this walk should show that same number of rows, all of them Updates. Whether the dollars are right is the tiles' job; what this walk tests is that every line finds itself.

Part A

The statement file, out and back

Money → Budget, List view. Export ▾ → CSV, then Import at the top of Money → Budget lines → the Simple list shape → choose that file.

A1

Every row says Updates

This is the whole test, and until 2026-09-10 it failed three different ways at once. Read the preview before touching anything.

Verdict
A2

The funding band is marked as funding

The file writes two bands, COSTS and FUNDING. Rows under the second one are money coming in, and the preview should say so where you can see it before committing.

Verdict
A3

Nothing the file computed comes back as a line

The file carries headings, subtotals and a closing ladder. None of them is a budget line, and a re-import that invented one would quietly inflate the plan.

Verdict
A4

Cancel — then the same plan as Excel

Cancel. Then Export ▾ → Excel and import that. Excel nests its lines with a real indent instead of the dash the CSV uses, so it is a genuinely different read of the same plan — and it is the format most coaches will actually use.

Verdict

Part B

The by-period file, out and back

Still on Budget, switch to By period at month grain. Export ▾ → Excel, then Import → Budget lines → the Month grid shape.

B1

The same answers, plus the schedule

This file spreads each line across months, so it carries something the statement file does not: when the money moves. A re-import that flattened it would rewrite every line's payment plan on commit.

Verdict
B2

Quarter grain — a known limit, not a defect

Known limit

Switch By period to quarters, export, and import that. A quarter column is not a month, and the importer will not split one into three — inventing dates a coach never typed is the thing this door is built never to do. So the rows come back named correctly but without amounts, and are refused rather than guessed at. This is the intended behaviour, and it predates this build. Seen and understood, not a Flag — unless you would rather it did something else, in which case say so in the notes.

Verdict

Part C

Everything that is not our own file

The band rule must not reach a sheet that never asked for it. These two steps are the regression check on every coach who builds their own spreadsheet.

C1

A hand-built sheet is still all spending

Import → Budget lines → Simple list → the paste tab. Paste three lines of your own with no headings at all — a category, a name and an amount per line, one of them deliberately named after a fundraiser (say Fundraising · Chocolate Sale · 1800).

Verdict
C2

The blank template still works, and now says how to plan money in

Import → Budget lines → Download a template (Excel). Open it.

Verdict

Part D

The one commit, and the help sentence

One step actually writes, so that "Updates" is proved to mean what it says rather than merely to read well in a preview.

D1

Commit an untouched round trip and watch the plan not move

Writes

Note Planned costs and Planned funding and the line count. Export the List as Excel, import it back without editing the file, and this time press Import.

Verdict
D2

The guide no longer states the old rule as a fact

Money → the ? → the import guide → Templates, and what an import will not do.

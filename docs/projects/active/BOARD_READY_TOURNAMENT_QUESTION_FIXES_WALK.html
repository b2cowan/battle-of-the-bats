Registration questions: archived answers, file links, file types

Board Ready ruling 15 (fixes F1–F3). Written 2026-11-20 against the dev build. One walk per job; tick a box only when you see what it says.

What this checks

  • F3 · the form: a File upload question takes a PDF, JPEG, PNG or HEIC only, checked from the file itself; all files together up to 9 MB; a refused file says why under its own question and you stay on the form.
  • F2 · the record: a file answer is its name, and clicking it downloads the file; the export says “Attached”, never a storage address.
  • F1 · archiving: an archived question leaves the form, but its answer stays on the team’s record under “No longer asked” and in the export as a “(no longer asked)” column.

It passes when every box is ticked as written. Not in this walk: waiting an hour for a download link to expire (the link is made with a one-hour limit; the unit tests pin it), every role’s access (the unit tests run the real access rule for coach, treasurer, official and an admin without Tournaments; the walk tries one), and the help article (read it at Help › Tournaments › Event settings if you like).

Before you start

  • Restart the dev server once (this change added new files): stop it, then npm run dev, and wait for “Ready”.
  • Test files are in C:\tmp\f3-walk-files: medical-form.pdf (a real PDF), fake.pdf (a web page renamed .pdf), notes.txt, big-scan.pdf (10 MB). For the optional step 15, an iPhone photo (.HEIC) if you have one.
  • Two windows: a normal one signed in as the owner, and a private window for the public form (it must be signed out).

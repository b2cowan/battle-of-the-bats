Two versions of one idea

Codex's first choice is Joined FL: the F's middle arm turns down into an L, so the name's two initials become one shape. This page draws it as Codex drew it, beside the same mark with my refinement. The refinement is warmer corners and Open F's rounded shoulder. The letters, the colours, the name beside it and every placement are the same in both. Nothing is built.

My recommendation: the refined version

Codex's version is thick square slabs with one small rounded corner. At tab and phone size it reads like a letter from a pixel font, which is the "terminal" feeling the project is leaving. Codex named the same risk ("too engineered"). The refined version keeps every proportion and the two-letter idea. It rounds the shoulder the way Open F does and softens every other corner by the same amount, so it reads as drawn and not computed. Its 16-pixel version evens the strokes, which Codex's left uneven, so the tab gains clarity.

What changed, and nothing else

The shoulder

The top-left corner, where the stem meets the top bar, becomes one curve, as on Open F. It is a little wider than the stem (12 of 64 against 10), so the stroke stays the same thickness all the way round (/design found a curve exactly as wide as the stem swells at its widest point). This is the biggest change, and it takes most of the "machine" out of the shape.

Every other corner

The outer corners get one small radius, the same everywhere. The inside corners get a smaller one. Codex rounded one corner and left the rest square, which reads as an accident at small size.

The 16-pixel version and the centring

Codex's 16-pixel F stem is 2 pixels and everything else 3, so the F looked thinner than the L. Refined, every stroke is 3 pixels and the gap stays 2. The shape's weight sits on its left, so on the tile it moves 1.5 of 64 to the right to look centred.

Unchanged

Stroke thickness at full size, the gap between the F and the L, the foot, the olive tile, the paper letters, the Inter name and the olive HQ. Codex's maskable placement too (84%, inside the safe circle).

Same in both columns

So only the mark differs, both lockups get /design's fixes: the mark beside the name is sized to the letters (about 1.4 times the capitals), and HQ is set a step heavier below 18 pixels so it does not look hairline beside the bold name.

In every place, side by side

The left column is always Codex's, and the right is always the refined one. The 16 and 32 pixel tiles are rendered at that size and then enlarged, so you see real pixels.

Carried forward, whichever version you pick

Codex and the first drawing agree on these. They are drawn above and need no new decision unless you want to change one (Ask 5).

  • Email shows the name as text in Arial, with no image. Outlook blocks images by default, and the email looks the same either way.
  • No lime in the mark on a page. The page's lime button keeps the one lime. Olive is the mark's colour. On Dark the mark takes the Dark text colour.
  • The new mark replaces the ">" in the admin and coaches-portal top strips, so one symbol appears in every shell.
  • Everything changes in one release, with the marketing restyle. That covers the tab, the phone icons, the notification badge, the export mark, the strips, every copy of the name and the new share card.
  • A line in What's new tells people their home-screen icon changed. An iPhone keeps the old icon until the app is added again.
  • The typewriter rules move: the typewriter face is now only for a plan chip and real data, and the one-wordmark rule describes this lockup.
  • Before anything is printed or stitched: a name and logo search on "FieldLogic" and on this mark.

The club’s name, its logo tile and the back link

One purpose: the head of the club’s sidebar. A small script changes the UAT club’s logo and name so you can see every case; one command puts it back. About 25 minutes.

Before you start

  • One command changes the club, one command puts it back. In a terminal in the project folder: node scripts/walk-logo-tile.mjs logo (also two, long, wide, tall, light, none, broken), then reload the page. Walk 1 tells you which one to run at each step. When you are done: node scripts/walk-logo-tile.mjs restore.
  • The waiting numbers on the sidebar rows still arrive a moment after the page. That is as before. What must not change after the page appears is the order of the rows, the Tournaments door at the foot, and the tile at the top.
  • Walk the parts in order, 1 to 4. Each opens with a stop check.

Already proved by tests and my own pass (don’t re-do these)

  • With scripts off (exactly what the server sends), the tile is already the logo or the initials, at the size it will keep: nothing swaps afterwards, for a logo, no logo, a wide one, a tall one, a very light one and a made stock logo. The one exception you accepted: a logo file that will not load shows a broken moment, then the initials.
  • The club cell is 45 px tall open and folded, and its bottom line meets the tab band’s line (both at 93 px on the page).
  • Uploading a picture stores its shape: a wide 6 : 1 picture, a tall 1 : 4, a square and a picture turned sideways by its camera were each stored correctly through the real upload.
  • The club’s Programs order and the foot’s Tournaments door are in the page the server sends.
  • Typecheck, spelling, the admin guards and the layout check on the club Overview, Rep teams, Accounting and the tournaments list pass at 361, 390, 768 and 1440 wide.

Your time goes on judgment: does the head of the sidebar look right, is the tile the same open and folded, do the two back links feel like one?

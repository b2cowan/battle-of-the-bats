Coach scores: the home coach enters, the away coach can report

Written 2026-11-03 for Stage 9e-3 (built, uncommitted). One purpose: the home team’s coach enters a game’s score from their own team page, the other coach can report it, and the league admin keeps or corrects it.

What this walk is for

Until now only the club could enter a house-league score. Now the home team’s coach enters it on their team page once the game has started, and it counts straight away. The away coach sees who entered it and can Report this score with a note; the score stands. The league admin sees a Coach entered or Reported tag in the game’s window, presses Keep or Correct the score, and finds what is waiting in a Scores to check fold. Nobody is emailed about a score.

It passes when

  • The home coach sees every started game of the team, newest first, with Enter the score on the ones with no score, and nothing for a game not started or postponed.
  • A saved score counts at once (the standing line moves), and the home coach can change or clear it until it is reported or the league admin looks at it.
  • The away coach reads the team, never the person (“Oak’s coach”), can report once, and the score stays as entered.
  • The league admin sees who entered it and the note, and Keep, Correct and ✓ with no change each close both coaches’ doors with the right line.
  • Scores to check lists reported scores first, empties itself, and is read only for the registrar.
  • A window that is out of date is refused with nothing changed, a division with standings off says “shows on the schedule”, and nothing private reaches the public pages.

Known before the walk

  • The dev server must be restarted first. This build adds new pages and a database change. Before the restart the coach’s Save answers “not found”.
  • No email of any kind. There is no score email and no report notification (your answer, 2026-11-03). A report reaches the league admin only as the first row of Scores to check.
  • Your four answers are built as you chose them: Keep closes both doors and both coaches read “The league admin checked this score.”; no Report on a club score, coaches read “The league admin entered this score.”; “Sent to the league admin” kept; Keep is offered on a Coach entered score too.
  • Build choices to confirm (say if any should change): the league admin clearing a score gives it back to the home coach to enter (E4); a finished season lists its scores with no doors (not in this walk); a postponed or cancelled game leaves the coach’s Scores list, even a rainout still held in Changes to send; the windows are the house 520 width, not 480.
  • A score the club entered before this build has no “entered by” line in the club’s window (G7): nobody recorded who typed it. The coaches read “The league admin entered this score.”
  • Times are relative to when you ran the fixture. G1 started an hour before it ran. Re-run it if you walk on another day.

Not in this walk

  • A finished season. No doors anywhere; the server refusal is tested.
  • A coach removed from the team, and two coaches on one team. Both are proved in the database check and the tests.
  • The rainout meeting a scored game. A rainout lists only games with no score, and a score saved after a rainout window opened is refused there. Proved by the tests.
  • The help article. Read it if you like (Help › House league › Record scores and standings); it is not a walk step.

Before he arrives

  1. On the morning of the demo, rebuild the world. Run npm run demo:milton:reset. Whether sign-ups are open, the early-bird price and "the coming Saturday" all follow today's date, so a world built days earlier drifts. The rebuild never signs anyone out.
  2. Double-click "Milton demo windows" on the desktop. Four full-size Chrome windows open, already signed in, slightly cascaded so every title bar shows, with the owner in front. Double-click it again any time to put them back in order and signed in. Your everyday Chrome is not touched.

  3. The first time only, name each window. Click the profile picture at the top right of each window and rename it to "Owner", "Admin", "Coach" or "Public", with its own colour. That is how you tell four Chrome windows apart at a glance.
  4. Move between people with the taskbar or Alt+Tab. Admin screens are wide, so on this screen they read best full size. For a side-by-side moment (his phone sign-up arriving in the admin's list), press Win+← on one window and Win+→ on the other.
  5. For his phone, double-click "Milton phone sign-in". It opens two fresh codes, one for the league admin and one for the coach. Scanning a code signs the phone straight in, with nothing to type. Each code is for one phone: if you scanned it yourself while rehearsing, double-click again for a new one before he scans.
  6. Try the rainout on a phone once before you offer it. It is the one admin job worth doing on a phone, but it has not been rehearsed at phone width yet. If anything looks cramped, do the rainout on the PC and keep the phone for the sign-up and the emails.

Saved links break on a rebuild. The admin's season screens carry an address that changes every time the world is rebuilt, so always click through from the house league home. The three codes above only point at addresses that survive it.

The agent proposes "announce" when

  • It changes how an everyday task works for existing customers.
  • A current customer can use it right away, with no setup or plan change.
  • It fixes something customers would have noticed.

The agent proposes "don't announce" when

  • It is wording, tidying or a fix to a rare case.
  • It needs a plan or setup most customers have not got.
  • The thing is obvious on the screen the moment it appears.

At most one line per release. "Don't announce" is a normal answer and will be the common one. Your yes or no is recorded with the release entry, so the Overview note and the "New" tag follow your decision and nothing else.

Eight things I need you to rule on. My recommendation is first in each.

Ask 1 · The What's new link inside Help

It is a good place to browse past releases.

Recommend: keep it, remove its dot. Alternative: remove the link and rely on the account menu alone.

Ask 2 · Where the row sits

Desktop: top of the settings group in the account menu. Phone: in the "You" group next to Account. The phone's bottom group has a fixed order from your 2026-10-17 ruling (Help, Send feedback, Download app, Sign out).

Recommend: as drawn. Alternative: put What's new right after Help in the bottom group, which changes that ruled order.

Ask 3 · A dot on the avatar

It would repeat the problem we are removing, on a new spot.

Recommend: no avatar dot. The Overview note is the signal; the "New" tag only helps once someone opens the menu.

Ask 4 · Where the row leads

I said earlier it would open inside the app. I checked: no in-app release page exists today. What's new is a public page that opens in a new tab.

Recommend: ship with the public page in a new tab (nothing new to build), and decide on an in-app page separately if you want one. Alternative: build the in-app page as part of this work.

Ask 5 · Note position

Under the title costs one line while it shows; at the bottom costs nothing but is easy to miss.

Recommend: under the title (After A).

Ask 6 · Coaches portal Overview

Only the club admin Overview is drawn. Coaches have a separate Overview.

Recommend: same note on the coaches Overview in a second step, after you have seen it work on the club side. The menu row and phone tile cover coaches from day one.

Ask 7 · The agent's rules and the one-line cap

The rules on tab 4 are my first draft of what counts as announce-worthy.

Recommend: approve them as a starting point; the agent quotes the rule it used each time, so you can tighten them as you go.

Ask 8 · Existing unread state

Everyone's browsers currently say "unread" whenever a new release appears. After the change, only announced releases light anything.

Recommend: past releases count as already read, so nobody sees a surprise "New" tag on day one.

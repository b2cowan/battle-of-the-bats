Editing a published game, and the changes that wait

Written 2026-10-28 for Stage 9d-2b, Part 3. One purpose; sign it off on its own.

What this walk is for

Once a division’s schedule is published, a game is no longer deleted or quietly rewritten: it is edited, and the change waits under Changes to send until the league admin sends it. This walk edits Walk U11’s published games and watches that happen: what a game’s window offers before and after publishing, a move that saves at once but waits, the public schedule keeping the old time until the send, Undo, a game moved twice or moved back, a window that has gone stale, a postponed game given a new date, and where a league admin may place a game compared with the owner.

It passes when

  • A draft game offers Delete this game and no Cancel; the same game once published offers Cancel this game and no Delete, and its Home and Away read as facts.
  • A moved game is saved at once, the header shows Changes to send with an amber count, the list marks the row “Moved · not sent”, and the public schedule still shows the old time until the send.
  • Undo puts one game back (its row and the count go). A game moved twice reads once, with the date families heard. A game moved and moved back reads nothing.
  • A window left open while the game changed refuses the press with “This game changed while its window was open…”, refreshes to the new record, and the next press works.
  • A postponed game given a new date reads “Moved” with “Was …”, and families will hear it as one move.
  • A league admin can place a game only on Walk U11’s own game times (anything else is refused in words); the owner can place it anywhere.
  • One Send makes the changes live: the count clears and the public schedule shows the new time, marked Moved.

Not in this walk

  • The families’ emails and the history that records them, the coaches’ copy, and the urgent cancel that goes on its own: walk §418. Dev has no email key, so nothing is mailed here either.
  • The club moving a division’s game time, and the coach’s own games page (Part 5).
  • Deleting a team on a published schedule. The server refuses it, but the screen no longer offers Delete on a published division’s teams, so there is nothing to press. It is covered by an automatic test, not by this walk.
  • The free League plan, where there is no club schedule and so no limit on where a game goes. The dev club (UAT Rep Club) is on the Club plan, so that half cannot be walked here.
  • Adding a game to a published schedule, Cancel this game and Put it back on. The cancel is walked in §418; the others are the same rules.

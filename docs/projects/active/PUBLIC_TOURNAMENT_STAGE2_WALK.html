The Overview answers the moment you are in

What this walk is for. Stage 2 rebuilt the Overview, behind the preview switch. On game day it is a short page: Live now, Up next, Latest results, News, then the host card. Before the event it is one Register card and a short list of facts. After the event the champions come first. The club's own card appears only when the organizer has a public club page. Families and the public demo see none of this until Stage 8 turns the preview on for everyone.

It passes when the preview on gives each moment its page, the numbers on the Register card match the data, a held-back division never appears anywhere, the band and the club's pages say the same word the day a champion is crowned, and with the preview off every page is exactly today's site.

What the Overview never shows now

  • An “Event Snapshot”, a “Tournament Day” heading, a row of Explore buttons, or the old Follow-a-team bar.
  • A follow button or an alerts control in an ordinary browser tab: following lives in the installed app only.
  • An empty card. A part with nothing in it is simply not there.

Not in this walk

  • The installed app's own Overview (the “Follow this tournament” line shows only there). It needs a secure address, which the dev server over Wi-Fi is not.
  • A club's “Open now at …” list with real sign-ups: no dev club has one open. Its words are pinned by unit tests. Part G has an optional step if you have one.
  • Tab order, tabs that appear and disappear, and Rules as tap-open sections: Stage 6. The bracket's move and Standings pinning: Stage 4.
  • The Schedule's controls and a game's page redraw: Stage 3.
  • The club home and Tournaments tab now say “Finished” for a crowned event even with the preview off (the club's pages are live today). That is the one change a family can see before Stage 8; Part F shows it.

## Calls this table makes (read before the rows)

1. **The line under the title is a plain count, like the Teams page.** The drawing tried "2 current and upcoming · 4 past";
   the section headings already split the two, so the line only needs the total: **6 tournaments**. One rule, no tense, and it
   reads like "10 teams" on the Teams page next door.
2. **"Current and upcoming", not "Coming up".** A live tournament sits under this heading, and "Coming up" over a "Live now"
   row says two things at once. Not "On now" either: the home already has "Open now" for sign-ups, a near-twin with a
   different meaning.
3. **One word for the place across the top: "tab".** The editor's rows already say "as a tab"; the card's opening line now
   says "tabs" too, never "top row" (the drawing's word, which nobody outside this project uses).
4. **The Tournaments row drops its count.** "Your 2 current and upcoming tournaments" needs a singular form that reads badly
   ("Your 1 current or upcoming tournament"). The row says what shows and where; the count lives on the public page.
5. **Past tournaments' empty line changes because of Ask 4.** Today it waits for an *archived* tournament; after 4f a
   finished one counts, so the line waits for a *finished* one.
6. **Past rows carry the year; current rows do not.** A current or coming tournament reads exactly as on the home ("Oct 24–26");
   a past one is read across years, so it says "Aug 14–16, 2026".

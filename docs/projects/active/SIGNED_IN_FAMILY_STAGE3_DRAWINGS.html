What this does

  • One address per sign-up, not per child. A parent signing up three children adds it once.
  • No name field. The second parent’s greeting in emails is “Hi,” as already ruled for the first-practice email.
  • Nothing about the box is required, so the sign-up takes no longer for anyone who skips it.

Cost

  • One more row on a long form. It sits with the other parent details rather than at the end, so it is found where it is expected.

Who gets which email

Recommended answers shown. “Both” means the registration’s first parent and the second parent’s address. Rows marked with an ask change if you rule differently.

EmailFirst parentSecond parentNote
Sign-up confirmation (with “Your sign-up”)YesYesThe second parent’s copy has the “who added you” line. Ask 2.
Accepted, moved off the waitlist, spot released, declined, withdrawnYesYesThese are about the child’s place, so both should know.
Placed on a team, moved to another teamYesYesRuled 2026-10-31. Becomes the team invitation in Stage 4.

Payment receipt, refund noticeWhoever paid / the first parent, as todayUnchanged. A receipt goes to the address on the payment.
Club “Email families” messagesYesAsk 4Counted once per household in “Will be sent”.
“Future seasons and club news” marketing listOnly if they ticked the boxNeverNobody can agree to marketing on someone else’s behalf. Ask 3.

Why the marketing line is firm

  • The tick-box is one person’s consent. The second address was typed by someone else, so it stays out of the marketing list unless that parent ticks it themselves later.

Unsubscribing

  • Emails about a sign-up carry no unsubscribe link today, and that stays. The “not you? tell the club” line is how a wrong address comes off.

For counsel

  • The privacy-law review already gating Stage 4 should also see this page. Nothing here is built on its outcome.

When it goes wrong

Second parent’s email
priya.shah@example.com

That’s the same email as yours. Leave this empty or enter the other parent’s.

SituationWhat happens
Box left emptyNothing changes anywhere. The finish screen names one address.
Same address as the first emailThe box shows the message above and the form does not send. Capital letters and spaces are ignored when comparing.
Not a valid address“Enter a valid email address.” in the same words as the first email.
A mistyped or stranger’s addressThey get the confirmation with the “who added you” line and a way to ask the club to remove them. They get nothing else unless a later email goes out to the household.
Someone using the form to mail strangersThe form’s existing limits apply to the second address on its own: the same hourly cap per address as the first, plus the per-visitor and overall caps.
Several children in one sign-upOne second address for the whole sign-up. Siblings stay one household.
Parent wants to change it laterAsks the club. Staff change it on the registration record. There is no parent-side edit until the parent has an account (Stage 4).
The second parent has already unsubscribed from this clubThey still get emails about the sign-up, which are not marketing. They stay off the marketing list.
Both parents sign up separately, each with the other as second parentTwo sign-ups, two households, as today. Duplicate matching is Stage 14’s job.

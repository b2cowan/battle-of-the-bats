A1A document already on file for this season

Its Last signed reads “2027 Season”, which repeats what the On file chip says. The alternative is a dash, but a dash could be read as “never signed”.

Recommended: show “2027 Season”. Every row then reads the same way, and nothing looks missing.

A2How a house-league copy is named

“Summer 2025” with “House league” on a second small line, the way the Seasons table on the same page names it. The row grows one line taller only when the newest copy is a house-league one.

Recommended: as drawn. The other option, “Summer 2025 (house league)” on one line, is a new way of writing it that appears nowhere else.

A3Earlier copies on a phone

The phone's sentence says what's owed now and has never shown history.

Recommended: leave the phone as it is. Looking up an old copy is a job for the desk, and the sentence stays one line. Option: the “Earlier copies” link drawn in tab 3 C.

A4Replaced medical consents become visible

Today a good-until-replaced document shows only the copy on file, and the older ones are hidden entirely. Under the new rule they count toward “+N earlier” and appear in the window.

Recommended: yes. A replaced consent is still a signed copy, and the window is where someone would look for it.

A5Opening a copy from the window

Each row in the window could open the signed file. That would let a club admin read a coach's uploaded papers, which raises the question of what club staff may see. That's a separate decision.

Recommended: not in this change. The window lists the copies. Opening them can be a later ask if you want it.

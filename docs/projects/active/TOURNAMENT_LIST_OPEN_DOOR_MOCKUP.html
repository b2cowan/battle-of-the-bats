Same section, same wording. Measured size: 44 px button, 390 px frame. Open this page on your phone for the real feel.

1 · Add one door to the window, and which placement?

The ruling on this list says no other controls on a row, and the whole row opens the record. This keeps that ruling for the row and adds one control inside the window, so it does amend the ruling slightly.

Recommendation: A, a "Manage" section at the top of the window.

2 · Where does the button land?

On that event's Dashboard, with that event chosen as the current one. It is the same page the event switcher lands on today.

Recommendation: Dashboard.

3 · Which events get the button?

Every event in the Active, Completed and Draft bands. Sealed records have no admin to open and keep their public link. Someone scoped to certain events only sees those events in the list anyway.

Recommendation: all events except sealed records.

4 · Should the club Overview also get a way into an event?

I did not find another door into an event's admin for a club in the code I read, other than this list and the event switcher. If you can reach events another way, that changes how much this matters. Worth a quick look at the Overview before building.

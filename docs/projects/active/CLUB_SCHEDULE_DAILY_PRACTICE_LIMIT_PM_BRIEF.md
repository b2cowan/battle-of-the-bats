# Club schedule daily practice limit — PM Brief

**Priority:** prevent surprising back-to-back practices when an admin generates a new club schedule.

New blank schedules start at one practice per team per day. The admin sees that choice in Settings before generating and can raise it or remove the limit when the club needs more time for each team. If a day offers more slots than teams, some slots may remain open; the setting explains this tradeoff.

Existing schedules and copies keep the daily limit already saved on them, including “No daily limit.” The separate weekly limit remains available under Rules. No schedule, coach, or Accounting permission changes.

If an admin manually drags a practice onto another day and it would exceed the chosen limit, the grid shows a warning. The admin can still make that deliberate exception; overlapping practices remain blocked.

**Success:** the default is visible, a generated draft respects it, and saved schedules are not silently reinterpreted. The owner confirms the layout in the browser.

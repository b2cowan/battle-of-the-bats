What changed
  • A white button joins the lime one, same height and same look as every other secondary button in the portal. Lime stays the one earned action on the screen.
  • The sentence loses its "or": with the start-from move gone from it, the quiet line only offers the drill library.
  • The plan does not move. The ghost row is the same height, so the scouting card, the sheet and the blank plan sit exactly where they do today. Nothing is pushed below the fold.

Asks

Four calls for the owner. Recommendations first.

1 · A button, not a chooser on arrival

Recommend: yes, a visible button on the blank plan. Do not pop the picker when the coach opens the plan: most coaches who open a blank plan want a blank plan, and the picker would be an extra tap for all of them.

This replaces the owner's earlier "quiet alternative" ruling for this one control only. The drill-library link stays quiet.

2 · The label

Recommend: keep "Start this plan from…" exactly. The help articles, the run sheet and the picker's own title already use it, so there is one name for it everywhere.

Alternative: "Copy a past practice". Clearer for a stranger, but it leaves out templates and past seasons, which the same window also offers.

3 · The scouting card above a blank plan

Recommend: leave it, and let the run sheet say so (done). With this change the blank plan's actions stay in the same place, so the card no longer competes with them.

Alternative: collapse it to a one-line row while the plan is blank. It costs a second design for a feature that is working as ruled.

4 · Phone included in this change

Recommend: yes, same build. The demo includes a phone moment, and the phone's blank plan has the same hidden link today.

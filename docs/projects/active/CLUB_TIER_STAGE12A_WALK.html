Before you start: two Stripe listen windows

Open two PowerShell windows and run one line in each. The Stripe CLI won't carry both kinds of event in one window. The CLI isn't on your PATH, so these use its full location.

Window 1: payments and refunds

C:\tools\stripe\stripe.exe listen --events-from @accounts --events checkout.session.completed,checkout.session.async_payment_succeeded,checkout.session.expired,refund.created,refund.updated,refund.failed --forward-to localhost:3000/api/payments/connect-webhook

Window 2: the club's account

C:\tools\stripe\stripe.exe listen --events-from "@self" --events "v2.core.account[requirements].updated,v2.core.account[configuration.merchant].capability_status_updated,v2.core.account.closed" --forward-to localhost:3000/api/payments/connect-account-events

Both print the same signing secret. Your local settings already hold it for both doors, so there's nothing to paste. If the CLI asks you to log in, run C:\tools\stripe\stripe.exe login once, or add --api-key with your test secret key.

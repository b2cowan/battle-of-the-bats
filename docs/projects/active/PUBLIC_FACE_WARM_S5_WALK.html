The system screens

Built 2026-10-23. One purpose: the six screens a person meets when something is missing or wrong (a page that does not exist, a page that crashed, no connection, an unsubscribe link, a paused account) look like one family, say only what is true, and give one obvious next step. Two small carry-ins ride at the end.

What this walk is for

Every one of these screens used to read like a terminal printout ("[DIAGNOSTIC]: ROUTE_NOT_FOUND"). Now each has a small olive icon tile, a plain headline, one sentence, one next step, and the FieldLogicHQ name at the foot. Warm paper for everyone signed out; Dark only for a signed-in person who chose it (the unsubscribe page is always paper). The words are the ones /marketing ruled in PUBLIC_FACE_WARM_S5_COPY.md.

It passes when each screen shows its tile, the plain words, exactly one lime button (the unsubscribe and paused pages have none), no typewriter capitals, and nothing scrolls sideways on a phone.

Steps you may not be able to do: a real crash cannot be forced from the product. I proved Try again recovers with a temporary test page (a page that fails for six seconds, then works): the new Try again recovered it on one tap; the old reset button stayed stuck. If you want to see the crash screens yourself, ask me to switch the test page on, then tick the steps. Those steps have a Skipped twin.

Not in this walk: the club site's own "not found" screen (a separate screen, unchanged); the paused page only reaching people with no active workspace (noted for its own plan); the marketing share card's squarer-preview crop (an S4 follow-up).

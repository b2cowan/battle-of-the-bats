Standings: the season’s rules, the switch, the coach’s line

Written 2026-11-01 for Stage 9e-1 (Parts 1–6, uncommitted). One purpose: the standings table ranks one honest way, says how, shows only when families should see it, and a game counts once both scores are in.

What this walk is for

Before this build the standings counted a finished game with no scores as a 0–0 tie, showed a table of zeros for a division whose schedule wasn’t published, broke a tie by the order the teams were created in, and called the columns GF, GA and Diff for a baseball season. Now the table follows the season’s sport (RF, RA, RD), a game counts once both scores are in, teams level on points are split by the game between them (only when exactly two are level), then run differential, then runs for, and teams still level share a place (“T-5”). A division can turn its standings off. A coach sees one quiet line about where the team stands.

It passes when

  • The public table for U11 Walk reads exactly as the fixture prints it, in the sport’s words, with the box that explains it.
  • A division whose schedule isn’t published, or whose standings are off, shows no table to families, and says why in a plain line.
  • The club’s admin table always shows, names who a shared place is shared with, and says when families can’t see it.
  • The Show standings switch saves when pressed, says so, and the public page and the coach’s line follow it.
  • Scoring a game moves the table (two teams level on points are split by the game between them), and clearing both scores puts the game back and the table with it.
  • A coach of a ranked team reads one line and a link; a coach of a hidden or unpublished division reads no line.

Not in this walk

  • A direct call that marks a game finished with no scores. The game window can’t send one (it holds one score alone, and clearing both sends “scheduled”), so the server’s refusal is pinned by unit tests rather than walked.
  • Other sports. House league offers softball and baseball only, and both read RF, RA, RD and 2 / 1 / 0. Basketball’s words are unit-pinned, not offered.
  • Coach score entry, rainout, “Final standings”. Those are 9e-2, 9e-3 and 9f.
  • The admin table on a phone. The drawing gave it a record column; this build keeps the admin table one scrolling table (see the calls below).

Own Address Live Run

Connect a real address to a dev club, watch it go live, break it on purpose, and take it away again. About an hour and a half, most of it waiting for the 15-minute check.

What this run is for

Everything built for a club's own address has so far been proven with fakes. This run proves it against the real thing: a real domain you own (b2cowan.com), real DNS in your AWS account, and the real host (Amplify) serving the club on it.

It passes when the club's pages answer on club.b2cowan.com with a padlock, the old address forwards to it for signed-out visitors, the row warns when you remove a record and clears itself when you put it back, and Stop puts everything back the way it was.

Not in this run: a design review of the screens, the words, or 390-pixel phone layouts (those are the two follow-up walks), and the plain-name forwarding at a registrar (this test name is not www, and Route 53 cannot forward).

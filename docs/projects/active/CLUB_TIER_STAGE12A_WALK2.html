Before you start: two Stripe listen windows (parts D and E only)

Part D takes one card payment and part E one refund, so window 1 is needed then. The account events window is only needed if you want to watch Stripe react to a Disconnect in part F, so it is optional.

Window 1: payments and refunds

C:\tools\stripe\stripe.exe listen --events-from "@accounts" --events checkout.session.completed,checkout.session.async_payment_succeeded,checkout.session.expired,refund.created,refund.updated,refund.failed --forward-to localhost:3000/api/payments/connect-webhook

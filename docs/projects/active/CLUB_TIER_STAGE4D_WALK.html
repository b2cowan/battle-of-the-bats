The club's sponsors

Written 2026-10-23. One purpose: a club lists its sponsors once in the Public site editor, families see them as a strip at the foot of the home page and a section at the foot of the About page, and a sponsor whose last day has passed leaves both by itself.

What this walk is for

Drawn at the Stage 4d drawings; words in CLUB_TIER_STAGE4D_COPY.md. Sponsors have a name (required), an optional logo, link and last day. No tiers: every sponsor gets the same space.

It passes when you can add, edit, end, renew and remove a sponsor, families see the right ones in both places and never an ended one, a bad logo is refused in plain words, and the phone pass is comfortable.

Not in this walk: the club's own web address (4e), sponsor tiers, click counts, anything to do with a team's own sponsors in the money book.

Before you start

Rebuild
The test club needs the three sponsors, so rebuild it first: node --env-file=.env.local scripts/seed-club-fixture.mjs --rep-only-club. It deletes and recreates "UAT Lakeshore Lynx" and resets that club's sign-in, so any saved sign-in for it needs signing in again. Do not run it in the middle of another walk.
Restart
This build adds files and a route, so the dev server needs a fresh restart.

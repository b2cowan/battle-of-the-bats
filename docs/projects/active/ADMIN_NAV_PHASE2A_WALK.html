The event at the top of the tournament sidebar

One purpose: the head of a tournament’s sidebar on a computer. The event now sits where the club’s name sits on club pages: its name, its logo (or the club’s, or its initials) and a small arrow. Clicking it opens the list of your tournaments; the old dropdown is gone, and Operations, Setup and Admin no longer fold. A small script changes the test event’s logo and name so you can see every case; one command puts it back. About 25 minutes.

Written Nov 10, 2026 against the dev site. Nothing here is real data: the club and its events are test data.

Before you start

  • One command changes the event, one command puts it back. In a terminal in the project folder: node scripts/walk-event-logo.mjs logo (also wide, tall, light, none, broken, long, two), then reload the page. It changes UAT Rep Club Invitational 2026 only. When you are done: node scripts/walk-event-logo.mjs restore.
  • The top strip is not part of this walk. It still names the event with its dates and its chip; Part B moves the page’s name there next. Settings & access and Tournaments still sit under Admin until then too.
  • Walk the parts in order, 1 to 3. Each opens with a stop check.

Already proved by tests and my own pass (don’t re-do these)

  • With scripts off (exactly what the server sends), the top of the sidebar is already the event, with its tile, for the club’s event and for a tournament-only organization’s, at 1440 and 1366 wide. Nothing about it changes after the page loads, and the tab’s title is as before.
  • The sidebar is 240 px wide on club and tournament pages alike; the event’s cell is 45 px tall and its bottom line is at the same height as the club’s.
  • The list is 320 px wide, under the cell (2 px below, lined up with the sidebar’s edge) or beside the folded tile; the keyboard opens it, moves through it and closes it back onto the cell; picking an event switches it on the same page; “All tournaments” opens the Tournaments page.
  • Uploading an event logo stores its shape; the 24 event logos already on dev were measured by the one-time pass. The rule for which picture shows (the event’s, the club’s, the initials) is covered by tests for every case.
  • Typecheck, spelling, the navigation guards and the layout check on the Dashboard, Divisions, Settings & access and the Tournaments page at 1440, 1366 and folded all pass.

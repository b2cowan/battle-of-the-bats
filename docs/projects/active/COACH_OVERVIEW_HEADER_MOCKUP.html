The Coach Overview header says the same two things twice, then floats a third thing between them

A review of the mobile Overview screen under /coaches/teams/{teamId} — where the sticky masthead, the scouting-book nudge, and the page's own title band stack at the very top of the screen.

Screen: Coach Overview, phone width Trigger: owner screenshot review Date: 2026-08-11 Status: proposed — not built
01

Two findings

Both come from the same root cause: chrome that repeats data the screen already shows one line above it.

Severity — High

Team identity stated twice in one screen height

The page's own <h1> repeats the team name and season that the sticky masthead already shows 8px above it. Every sibling page (Roster, Money, Team Calendar, Tryouts…) titles itself with the page's own name instead — Overview is the one outlier.

Severity — Med-High

The scouting nudge reads as an orphaned third bar

It sits in plain page flow under a sticky masthead, with its own card border and margin — a floating notification wedged between two headers. It also restates the opponent and "today," which the masthead's own Game day line already states one row up.

03

What actually changes

Unchanged

Masthead's team name / season / record / Game day stack, Premium & tier badges, Season setup chip, Help button, page content below.

Restyled

Page <h1> (team name → "Overview"), subtitle (drop season), scouting nudge (moved into the masthead, copy trimmed).

Removed

Duplicate team-name heading, duplicate season line, the nudge's card border / radius / floating margin.

Five push-backs, before the drawings

1 · "Publish schedule" is named three times and defined nowhere. It is the shape of the whole stage.

  • What the code does. A game is public the moment it is saved, generated or typed . Moving one tells nobody . The season’s only publish is a division’s teams (9c), and it has no unpublish.
  • Three honest options:

    A · No publish step

    • Games are live as saved; every change to a game emails families.
    • Convenor: can’t build in peace. Generating 12 divisions would email families 12 times, or, if new games don’t notify, families find a half-built season on the public page.
    • Family: sees drafts.
    • 9e rainout: fine, but every edit is a rainout.

    B · A draft until "Publish schedule"

    • Per division, like Publish teams. Publishing emails each family once.
    • Convenor: builds, checks health, then publishes.
    • Family: sees "the schedule is coming" until then, then the whole thing.
    • Gap: it says nothing about changes after publishing, so the first moved game is the same silent edit as today.

    C · B, then held changes (recommended)

    • After publishing, a change to a published game waits under Changes to send, an amber count. Send shows exactly what goes out, then the changes go live and are emailed together.
    • Convenor: moves ten games, sends once.
    • Family: one email per household per send, and the public page never shows a time nobody was told.
    • 9e: the rainout is the same path with one game and an immediate Send.
  • Why held, not live: the club scheduler already does this. A finished schedule’s edits wait until "Send the changes". A convenor who uses both should meet one rule, and the house rule is that a change which tells families is held until ✓.
  • Unpublish: recommended none, as in 9c. Once families have a schedule, taking it away is a change they can’t see. A wrong schedule is corrected with changes, or by cancelling games, which families hear about.
  • A half-published season is per division: the public page lists published divisions and says "U9’s schedule is coming" for the rest.

Define once, use all season

Define a metric

Say what to record so it is recorded the same way every time.

Record a number using the same method each time.

Every attempt is kept. The headline is what rows and charts lead with; the average and the spread are always behind it.

A range test has no “best” attempt. Its headline is how many attempts landed in the range, or the average.

Your words, in your order. “Not observed” stays separate; it is an evidence state, never the lowest rung.

More options

Precision and plausible input bounds for a test; optional context prompts for an observation. Defaults come from your method, never from a universal benchmark.

Changing a definition later

Rename fixes a typo and keeps the series. Changing the unit or the method starts a new definition and retires this one — every saved result stays under the name and unit it was recorded with, and the two are never drawn as one line.

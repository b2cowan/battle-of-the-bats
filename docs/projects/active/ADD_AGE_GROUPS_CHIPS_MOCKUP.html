3 · Calls I made that you haven’t ruled on

Both windows are drawn in the warm look. The build uses the portal’s colour tokens throughout, so Dark follows without a separate drawing; I would check it in the browser once built.

  • Ticked chips versus “+ U8” suggestion buttons. The owner ruling of 2026-10-12 for New tournament’s divisions says common choices are suggestions that leave the list once used, never rows to tick. This window already wears ticks, and your tap-again surprise comes from that. I drew the toggle because it matches what you expected here. The other consistent answer is the suggestion pattern: no ticks, a used chip disappears, and the row’s × brings it back.
  • Where the name style is remembered. The switch here resets on every load, because this page can’t save anything. In the product I recommend it is remembered for the whole club, so a laptop and a phone agree. The alternative is this device only, which needs nothing extra stored but makes each person set it once.
  • The + sits on every age group’s last row. The alternative is one quiet link at the end of the list (“Need two divisions for one age group? Add another”), which keeps the rows cleaner but is harder to find.
  • Tapping a ticked chip removes its row even if you have filled it in. The alternative is that the chip only removes a row you haven’t touched, which protects typing but makes a tap sometimes do nothing.
  • A blank birth-year box shows an amber outline instead of the per-row sentence. The alternative is no marker at all and relying on the foot.

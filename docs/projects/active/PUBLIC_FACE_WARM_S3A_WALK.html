The public face, warm · S3a · one envelope for every email

One purpose: every email the platform sends is the same white card with dark text, one lime button and the unchanged wordmark line. Before this build only the verification and password-reset emails were; about 45 others, and five with their own shells, were a near-black card with a lime banner.

The words are unchanged except four things the copy pass settled (docs/projects/active/PUBLIC_FACE_WARM_S3A_EMAIL_COPY.md): the Premium welcome's first line, the coach portal link at the foot of coach emails, the arrow dropped from button labels, and the forced capitals dropped from box titles. The "FieldLogicHQ · Canada" sign-off and the registration email's "does not process online payments" line are held as they were.

Parts A and B need only the dev server. C needs a place that really sends mail. D is optional.

Where and who

Dev server
http://localhost:3000. Restart npm run dev first: this build added files and changed shared modules, so a server that was already running will not show it.
Part A
/dev/email-preview. No sign-in.
Platform admin
/platform-admin/login. Email and password: UAT_PLATFORM_ADMIN_EMAIL and UAT_PLATFORM_ADMIN_PASSWORD in .env.local. Keep this page private if you paste them anywhere.
Coach (Part B step 4, Part D)
A coach whose team has Player dues set up. JORDAN from the Club Tier 4c-2 walk (head coach, 15U AAA) is the usual one; use any coach with dues if his team has none.
Mail apps (Part C)
Your own inbox in Gmail, Apple Mail and Outlook, in light and dark mode. Each has a Skipped step if you do not have one.

Before you start

  • Written 2026-10-23 against the working tree on dev, before the commit. The change is a look, not behaviour: who gets which email and when did not change.
  • Mail apps differ. Outlook's desktop app draws squarer corners and ignores some padding; Gmail and Apple Mail may darken a light card in dark mode. Only unreadable text, a missing button or a cut-off card is a defect.
  • If a step's words don't match, tick nothing, write what you saw in that part's notes and mark Issue.

3 · Page one, at true size

Letter paper, 8½ × 11 in, at the size it prints, with the recommended answers. The colour bar across the top, the logo-and-name band, the grey hairline and the footer are what every FieldLogicHQ PDF already draws. This file sits with the schedule and results printouts as one family. Tick Print the paper in black and white above to see it from a school-office printer.

The file, page 1 New the document Unchanged the kit’s header and footer

The header The kit’s 8 mm colour bar is drawn in the tournament’s colour. The logo follows, then the event’s name, then a line with “Tournament rules”, the dates and the host. The section headings take the colour, and every rule prints black. A long name breaks onto a second line instead of running off the page, a small change to the kit’s header.

The stamp Nothing records when a rule last changed, so the stamp says when this copy was made, on the tournament’s clock. It also carries the page’s own “subject to change” sentence and the live page’s address, with a code that opens it.

Sections The organizer’s icon, the number and the title. Each point has a hanging number in a column sized to the widest number in the file (“12.10” fits).

Type Helvetica, the kit’s one face: rules at 10 pt, headings at 12 pt, the name at 14 pt.

The footer The shared footer prints the date as 2026-11-18, as on every FieldLogicHQ PDF. The automatic check on every PDF proves it is on every page and that no text runs into it.

Running onto page two. A point never splits across pages. A section that splits keeps at least two points on each side; otherwise it moves whole to the next page.

6 · Asks

Settled, not asks (standing constraints from the plan and the code):
  • The file reads the rules through the page’s own checks. A Rules page switched off, an unpublished tournament, or a section held back with its division never prints.
  • There is no download when there are no rule sections (tab 2).
  • The look follows the band’s rule (tab 5), and the paper is letter size.
  • It is made with the same PDF kit as every other FieldLogicHQ PDF, header and footer included, and goes through the same automatic check.
  • The plan held this behind the preview switch “until Stage 8”. Stage 8 has shipped and the switch is gone, so this reaches customers on its own release.

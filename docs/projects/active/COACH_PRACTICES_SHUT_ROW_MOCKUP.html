The tension

Worth saying plainly before drawing the fix.

D6 was ruled and built today, and it was ruled the direction it was on purpose — the written warm-up alone went from 743px to about 480px by cutting the shut row down to almost nothing. Adding detail back in reopens that exact call. It's not the wrong ask, though: reading a plan top-to-bottom to understand its flow is a different job than confirming a block opened correctly, and D6 never tried to serve the first one. The fix below is deliberately narrow — one line, not the whole preview — so it doesn't just walk the height back to where Stage 2 started.

Proposed — one more line, not the whole preview

"What you're watching for" sits right next to "what you're doing" everywhere else in this plan — the field screen, the station card, the printed sheet. The shut row is the one place that only ever said half of it.

Setup and Equipment stay out of the shut row. They're logistics for the coach's OWN prep, not the flow a reader is following — and both already have a home: Equipment on the "About this practice" shelf above the timeline, Setup inside the open block once a drill's read-only detail is showing. Repeating them on every row is exactly the height regression D6 was ruled to avoid. Coaching-points stay dropped too, for the same reason D6 gave the first time.

Height cost: one more line only on a block that has a "watching for" written — for a typical 4–5 block practice, roughly another 70–90px total. Still a fraction of the ~480px a single open block cost before Stage 2.

The coach’s Schedule, and house league’s games following the club’s time

Written 2026-10-28 for Stage 9d-2b, Part 5. One purpose; sign it off on its own.

What this walk is for

Two halves of one change. A house-league coach’s team page now lists the team’s schedule: the published games as families last heard them and the team’s practices, from today on, with any game waiting for a new date after them. And when the club’s owner moves or takes back the time house league uses for games, the division’s games go with it: a draft division’s just follow, a published division’s wait in its Changes to send for the league admin to give out, and a game that no longer fits goes to Needs a new date.

It passes when

  • A coach on a draft division sees no games, only “isn’t published yet”; once published, the team’s games and practices appear together, from today on.
  • The club’s Send the changes lists a “Walk U11 games · …” row for each time that moved or was taken back, with no tick box, and says nobody is emailed from there.
  • A draft division’s games move or come off the draft at once; a published division’s games wait, and a game that no longer fits reads Needs a new date.
  • Until the league admin sends, the coach (and the public) still see the games as families last heard them; after it, the move reads Moved with its Was line, and the other game sits under Needs a new date.
  • The league admin’s Changes to send names the club (“The club moved Walk U11’s game time.”) and offers no Undo on it; the bell says how many games wait there.

Not in this walk

  • A game already played staying where it is: Walk U11 has no played game. The database check (T1 to T7) proves it; it is not walked.
  • The Undo refusal line (“The club moved this game’s time, so it can’t go back…”): the button is not offered, so the line is only reachable from a stale window.
  • The families’ email for a moved or postponed game and the coaches’ copy: the league admin’s send is Part 4’s walk (§418), and dev has no email key.
  • The club send’s rep teams, rep coaches and house-league practices (11b’s walk, §402), and a phone.
  • A game that moves but no longer fits its new slot: this walk reaches Needs a new date by taking the time back.
  • The help articles: rewritten once for all of 9d-2b in Part 7.

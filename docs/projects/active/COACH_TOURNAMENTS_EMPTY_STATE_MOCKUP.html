The general fix, not just this page

This only bites when both halves of a page are simultaneously empty — a coach with existing entries or existing hosted tournaments never sees this, because those sections render actual content, not a second onboarding illustration. The trigger is specifically two "nothing here yet, here's a big button" blocks landing on the same screen.

Going forward: when a page can offer more than one starting action, it gets one empty state with equal-weight choices, not one action's empty state followed by another section's empty state underneath it. The second one only earns its own illustrated card once the page already has real content above it.

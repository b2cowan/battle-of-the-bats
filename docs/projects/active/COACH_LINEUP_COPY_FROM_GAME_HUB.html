Product-manager brief

Copy a lineup from another game

What changes for the coach

The lineup builder gets a Tools ⋯ menu holding three things: Copy from, Print and Save as template. The tools a coach uses while building (Call up, Undo, Redo, Clear) stay on screen.

Copy from opens a panel with a Games / Templates switch. Games lists the season’s earlier games that have a lineup, newest first, in month bands. A coach picks one (or a template) and chooses what to bring across:

  • Batting order: the same order as that game. Positions already on this game stay put.
  • Order and positions: the whole lineup as it was, pitcher included. The coach sees who played where last game and moves players from there. (“Frances had three innings at third, so give her some outfield.”)

The copy lands in one step and one Undo takes it back. A player marked Out still comes across, and today’s warning flags them. A call-up in the copied lineup comes across too, called up for this game. Templates offer the same two choices. On a phone, Copy from fills the screen above the bottom nav.

Why it matters

Tournament weekends are when coaches reuse a lineup most. Today the only way to reuse Saturday’s lineup on Sunday is to save it as a template first. That takes four screens and leaves a throwaway template behind every weekend. This change puts the coach’s real habit, “same as last game”, two taps from the grid.

Customer impact

Every coach on the lineups feature, at least once per tournament weekend and often between back-to-back league games. The toolbar also gets calmer: four editing tools and one menu instead of six squares. The cost is one extra tap to print.

Priority

Small and contained. It reuses the builder’s save path and warnings and the portal’s existing Tools menu, and touches no data model. It also retires a known small defect: answering “Keep current” bounced the coach out of the Templates drawer.

Open for the owner

  • A ruling of “as drawn” on round 3: the Tools menu, the Games / Templates switch, earlier games only, and Print one tap deeper.

Success criteria

  • A coach copies Saturday’s lineup to Sunday’s game from the builder without making a template.
  • Fewer single-use templates get created around tournament weekends.
  • No support question about a missing call-up, a vanished player, or where Print went.
Full plan

Copy a lineup from another game

Source: COACH_LINEUP_COPY_FROM_GAME_PLAN.md. Drawn 2026-10-02; rounds 2 and 3 the same day. D1–D8, D11 and D12 ruled; D9 and D10 closed by D11; “as drawn” owed on round 3.

1. Problem

A coach who wants Sunday’s lineup to match Saturday’s has one route today: open Saturday’s game, save it as a template, open Sunday’s game, load the template. Tournament weekends are when coaches reuse a lineup most, and every one of them leaves a template behind that nobody uses again.

2. Findings

F01 — A game’s lineup can only be reused by first making it a template.The builder’s Templates drawer lists saved templates and offers to save this lineup as one. Nothing reads another game’s lineup. The workaround costs four screens and leaves a throwaway template in the library.
F02 — “Keep current” bounces the coach out of the drawer.This defect predates this project (Mobile Experience plan §13.6 #5, on the owner-calls TODO line). Loading a template over a lineup with positions opens a confirm dialog outside the drawer. Answering “Keep current” also counts as a tap outside, which closes the drawer. The proposal replaces that confirm with a step inside the panel.
F03 — The template-load notice blames the roster for a choice the coach made.“Skipped N players no longer on the roster” counts every template player who is not in this game’s current lineup, including players the coach took out of this game. The copy brings rostered players across, and the notice names only players who have left the team.
F04 — The notice asks the coach to save a page that saves itself.“Loaded “X” — review and save when ready.” The lineup autosaves. The new notice says what happened and nothing more.
F05 — A seventh square does not fit the phone’s tool row.Round 2 asked for a Save square beside Print. On a phone the row holds six 44px squares 8px apart, 304px. A 360px phone has 328px inside its 16px gutters, so seven squares (356px) break it. Closed by D11: the row becomes Call up, Undo, Redo, Clear and Tools, five squares in 252px.
F06 — A disk promises a save the page already made.The builder autosaves through the floating pill, so a disk beside Print would read as “save this lineup”. Closed by D11: Save as template is a worded item in the Tools menu, so it needs no icon.

3. What the coach sees

  1. The toolbar (D11): Setup, then Call up a player, Undo, Redo, Clear and ⋯ Tools. Tools is the portal’s existing menu: a worded button on desktop and a bare ⋯ on a phone, opening a sheet titled Tools. It holds three items, each with a one-line hint: Copy from… (“A previous game’s lineup or a saved template”), Print… (“Dugout poster or batting order card”) and Save as template… (“Keep this lineup to reuse on any game”).
  2. Copy from opens its own panel where the menu was: a title, a Games / Templates switch (D12), and the chosen list scrolling under them. On a phone (≤640) it fills the screen above the bottom nav, with “Into vs Komoka Kings · Sun, Oct 4” under the title (D7). At 641–900 it is a bottom drawer, and on desktop an anchored panel.
  3. Choosing a source asks one question in the same panel: Batting order, or Order and positions, with Back to the list. When this lineup already has positions, one line says “This replaces the lineup on this game. Undo brings it back.”
  4. After the copy the panel closes, and the notice above the grid says what was copied and from where. One Undo reverses it. Before game time the lineup returns to Draft, like any edit.
  5. Print… opens today’s print panel unchanged: the poster with its Landscape / Portrait turn, and the batting order card. That is one tap more than today.
  6. Save as template… opens a small window with a name field and a Save template button. Making a template is a create, so it asks. On a phone it is a short drawer that covers the nav, because it is a form.
  7. No prompt on a blank lineup (D4).

4. The rules

4.1 Order and positions copies everything (D2)

It copies the batting order, who starts (nine-player), every inning’s positions including the pitcher, the format, the innings, and the game’s rule changes from Setup. Assumed, confirm on review: the game’s notes and each player’s note on that game are not copied, because both are about that day.

4.2 Batting order only

This game’s format, innings and rules stay. Players take the source game’s order. Players on this game who did not bat in the source go to the bottom in their current order. Each player’s positions on this game stay with them. In nine-player ball, who starts comes across when both games are nine-player; otherwise this game’s format decides.

4.3 Who comes across: as is (D3, D5)

PlayerWhat happens
In the source, on the rosterComes across, even if the coach had taken them out of this game’s lineup
In this game’s lineup, not in the sourceStays, at the bottom of the order, with no positions; the check reports them undecided
Marked Out for this gameCopied as is. The status line and the Lineup check already warn and carry their one-tap fix.
Left the teamSkipped, and named in the notice
A call-up in the copied lineupComes across, called up for this game too, in either mode, and named in the notice
How a call-up comes across. A lineup cannot hold a player who is neither rostered nor called up to that game, so the copy calls them up for this game first, then lands the rows. Undo puts the lineup back but leaves the call-up on the game, out of the order, where the existing remove control takes them off.

4.4 Templates get the same choice (D6)

Loading a template goes through the same two-way step. This retires F02.

5. The lists (D12)

  • Games: this live season’s games that started before this one and have a saved lineup, not cancelled, newest first, banded by month (the band stays pinned as the list scrolls). Each row reads opponent, then the date and start time written out, then the innings. Later games are not listed.
  • Templates: every saved template, as today, name first and then format and innings.
  • The switch opens on Games, unless no earlier game has a lineup and a template exists, in which case it opens on Templates.
  • Empty: “No earlier game has a lineup yet.” · “No saved templates yet. Save one from Tools › Save as template.”
  • No search. The game a coach wants is nearly always in the top rows. Add search only if long lists turn out to be a real problem.

6. Out of scope

  • A prompt on a blank lineup (ruled out, D4).
  • “Copy to next game” from the games list.
  • Continuing the order where the last game ended. Nothing records who batted last.
  • Copying from a later game, or across seasons.

8. Build notes

  • Tools is the portal’s existing toolbar menu (the one the club Ledger uses): a worded trigger on desktop, a bare ⋯ on a phone opening a sheet titled Tools. It is a menu, so on a phone it stops at the nav’s top edge.
  • No new write path. The copy maps rows on the page and the ordinary autosave writes them. A call-up is linked with the existing call-up add, awaited before the rows land.
  • Reads. The games list comes from the events read the Lineups room already uses, fetched when Copy from opens. The source lineup comes from the existing per-game lineup read. Both are sequence-guarded.
  • One pure mapping function serves game and template sources, unit-tested for order only, order and positions, missing, extra and departed players, a call-up, nine-player and everyone bats, and a different inning count.
  • Guards move with the change. The lineup phone guard pins today’s row and its drawers. The row becomes Call up, Undo, Redo, Clear and Tools. Print, Templates (now Copy from) and the template form move behind Tools. Copy from is a menu that is full screen at ≤640, and the Save window covers the nav. Update each pin rather than deleting it.
  • Checks: verify:changed; the layout sweep on the lineup builder at 361, 390, 768 and 1440; the spelling gate.
  • Help: the Lineups article gets “Copy a lineup from another game” and learns where Print and Save as template went.

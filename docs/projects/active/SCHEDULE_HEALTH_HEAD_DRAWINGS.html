The button is an ordinary outlined button at the admin's one control height, the same as Export. The caption the row shows today ("Review · 3 issues") moves into the window's first line (specimen 3) and into the button's spoken name ("Schedule health, 78 out of 100, 3 issues"). That is deliberate: the pill is a count, the colour of the score is the verdict.

3 · Tapping it opens the panel in the product's standard window

This is the panel that opens under the row today, in the 640-wide window the product uses for a form, over the dimmed schedule. Close it with the ×, Esc or the phone's Back. A tap outside does nothing, because the window holds the rules form, and a tap outside a form never closes it. Its content is the same. Two things move: the score and caption become its first line, and "Adjust the rules" moves from the top to the end of the body.

6 · The dashboard reads the same number and opens the same window

Why they differ today. The dashboard works out its own health score and leaves playoff games out. The schedule counts every game. On a playoffs-only tournament the dashboard finds no games at all and says "No timed schedule generated yet", while the schedule scores the bracket. On a pool-and-playoff tournament the two give different numbers. The dashboard also leaves out the venues, so its venue-move figures can differ too. And it opens its own copy of the panel, with different tiles and only the top issue.

The fix. One calculation and one window. The dashboard counts the same games with the same rules and shows the same number as the schedule. Tapping its health row opens the same window as the schedule's button, specimen 3. The row stays a card on the board, where you can still hide or reorder it. It only stops opening in place.

What moves with it

The demo. The public demo's tour has a step that rings the health row and asks a visitor to drag a game onto a busy slot and "watch this score react". With the panel in a window, the schedule is dimmed and can't be dragged while it is open. The button fixes that rather than breaking it: its score sits in the header and changes as the game is dragged. The tour's ring moves to the button, the "Try it" line moves out of the window into that tour step, and "Put it back" goes with it. The tour's words are for the next demo pass.

While you edit a bracket the button hides, as the row does today. On a locked tournament the window opens but "Adjust the rules" is not there, as today.

5 · The alternative: in the event header, always in view

The only header that stays put while you scroll is the event header, beside Public site. Putting health there keeps it in view down the longest day. The cost is that this header is on every tournament page (Overview, Teams, Results and the rest), so health would sit beside Public site on all of them. And the Overview's board already has its own health row, so that page would show it twice.

The number fix (A7) is committed on its own. The button, the window and the dashboard's window are building next.

  1. A1 · Where the button lives. In the schedule's own header beside Export (specimens 1–4) RECOMMENDED, or in the event header on every tournament page (specimen 5). I recommend the schedule header: health belongs to the schedule, and the clash labels on each game already warn you while you scroll.
  2. A2 · The container. The product's standard 640-wide window RECOMMENDED. The written window rules cover questions and forms and have no side drawer. A drawer would be a new shape for this one panel.
  3. A3 · "Adjust the rules" moves to the end of the window. It is the rare door, and a rare door ends the body. Today it sits at the top of the panel RECOMMENDED.
  4. ⚠ Correction, after the ruling: the house league schedule has no health score and no health row. It shows only a clash warning box, from its own check. A4 below rested on a wrong fact and is held for a fresh call.
  5. A4 · The house league schedule follows. It wears the same health row at its foot and would get the same button, so the two schedules stay the same RECOMMENDED.
  6. A5 · The dashboard keeps its row but shares everything else (specimen 6) RECOMMENDED. It shows the same number as the schedule and opens the same window, before the event and on game day. The row stays because the board is made of cards you can hide and reorder. A header button there would be a second way to show the same thing.
  7. A7 · Ship the number fix first, on its own RECOMMENDED. The dashboard is wrong today on any tournament with playoff games. That doesn't need the button or the window to be ruled.
  8. A6 · On a phone, a pulse icon with the count as a badge RECOMMENDED, or the bare score with its count. The icon keeps the phone header's icon-only rule; the score would be the one header action that is a number.

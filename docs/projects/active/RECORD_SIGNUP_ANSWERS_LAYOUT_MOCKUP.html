Four calls for you. My recommendation is first in each.

  1. 1 · Stack every answer under its question, on desktop too? Yes. The other way to fix it is to keep label-left and only change the file row, but long questions would still push answers to the second line, so you would be back here with the next long question.
  2. 2 · Where does the audit line live? Under the box, once (A). B keeps it under each file, left-aligned. Either way the sentence stays as written.
  3. 3 · “Not asked” muted? Yes, plain muted, no italic. Today an empty answer is bold like a real one, but the product already shows these states in the muted “dim” ink, and italic is kept for placeholders and waiting slots. The same muted ink would cover the “removed” states in tab 2.
  4. 4 · Documents box gets the same stacked layout? Yes, in the same change. Its long tick note breaks the old layout in the same way. The shared Fee box (Price, Still owing) is left alone because short facts suit label-left.

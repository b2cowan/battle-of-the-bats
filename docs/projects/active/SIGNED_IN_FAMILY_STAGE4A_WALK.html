Family app walk · Stage 4a

A parent gets an invitation in the placement email, joins once, and sees every child's team. Every step below says where to click (Do) and what you should see (See). Allow about two hours: part 0 builds the test families, and the rest uses them in order.

Before you start

App
http://localhost:3000 with the dev server running. If you have not restarted it today: stop it, delete .next, run npm run dev, wait for Ready.
The club
Organization Dev League Org (address /dev-league-org/admin). The season is Dev House League 2026, with two divisions: Division A (teams Cardinals, Jays, Orioles) and Division B (Tigers, Cubs, Braves). Both divisions were already published on Oct 26, so there is no Publish button to press anywhere in this walk. You get the placement email by placing a child on a team or by pressing Send again (parts 1 and 7 explain).
Club admin login
One of the club's owner or admin logins: owner@dev.local (most recently used), league-owner@dev.local or league-clubadmin@dev.local. Use the password you normally use for dev logins. This is your main window and you stay signed in there all walk.
Parent inbox
Your own Gmail with "+" addresses, which all land in your one inbox. This walk assumes your address is b2cowan@gmail.com; if it is not, swap in yours everywhere you see b2cowan+…. Each email's "To" line tells you which family it is for.
  • b2cowan+mum@gmail.com the first parent
  • b2cowan+dad@gmail.com the second parent
  • b2cowan+kids@gmail.com the family with three or four children
  • b2cowan+owes@gmail.com the family that owes money
  • b2cowan+adult@gmail.com the family of a player aged 18 or older
  • b2cowan+rep@gmail.com the rep-club guardian (part 9)
Parent window
A private window for whoever you are pretending to be. All private windows of one browser share their sign-in, so only one parent can be signed in at a time there. Sign out before you switch to the next parent (account menu, the person icon labelled Account). To be two people at once, open the second one in a different browser.
Rep coach login
uat-club-coach-15aaa@uat-rep-club.local, password UAT_REP_CLUB_COACH_PASSWORD in your .env.local. The coach is head coach of "15U AAA" in UAT Rep Club.

Every test child below has the surname Walkthru, so you can find and clean them up afterwards.

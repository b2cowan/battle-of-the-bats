Before you start

Sign in as the bookkeeping owner and open Platform Admin → Bookkeeping. Download the synthetic preview file from the page, or use the fixture CSV.

B3-P1 · Check the private page and sample file

Confirm the import preview appears above the expense form and the synthetic CSV download works. Check that the page still requires the authorized owner session.

B3-P2 · Review the valid rows and source scope

Select BOOKKEEPING_B3_IMPORT_FIXTURES.csv. Expect 9 rows: 7 ready, 1 needing attention, and 1 repeated identity. Confirm both the platform balance and the connected account scope are shown, and that subscription sale, processor fee, linked refund, fee refund, application fee and payout transfer appear as separate movements.

B3-P3 · Confirm currency totals stay separate

Ready CAD movements should net to CAD $0.00. The USD movement should show separately as USD $12.34. The incomplete and repeated rows are excluded from ready totals.

B3-P4 · Inspect the duplicate and incomplete refund

Confirm the repeated sale is labelled “Repeated identity” and the orphan refund explains that parent_movement_id is required. The preview must not silently treat the repeated sale as another movement.

B3-P5 · Confirm the file stays local and nothing posts

Look for the “Preview only · no records posted” status and the Revenue handoff notice. There should be no accept/import action. Refresh the page and confirm the expense register is unchanged.

B3-P6 · Check malformed input handling

Select a non-CSV file or a CSV with a required column removed. Confirm the page reports the issue without crashing and offers no posting action.

Current boundary

This walk covers only fixture preview. It does not prove persisted deduplication, replay or interruption recovery, bookkeeping entries, payout reconciliation, production mapping, or tax attribution. Those remain later B3 gates.

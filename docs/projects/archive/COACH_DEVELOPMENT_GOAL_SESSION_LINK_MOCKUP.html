My recommendation

A

Ask it right there. The field already exists, tested and live on two of the three doors today — this is the third door catching up, not new product. It costs an uninterested coach nothing to skip, the same way the descriptor and the note already do.

B solves the same problem with more surface area to maintain — a new grid-row state, a second interaction, a second thing that can go stale — for a smaller discoverability win than just asking once, in the moment, the way the other two doors already do. C actively works against the point of this fix: the whole failure today is that a coach doesn't know the option exists, and hiding it behind a "+" is a milder version of the same problem.

# Schedule health in the header — PM brief

**What changes.** A tournament's schedule health moves from a full-width row at the bottom of the Schedule to a small button
at the top, beside Export. It shows the score in its colour and, when something needs a look, the number of issues. Tapping
it opens the health panel in the product's standard window. On a phone it is an icon with the count as a badge. The
dashboard shows the same number as the Schedule, because both now calculate it the same way. Before, the dashboard left
playoff games out.

**Why it matters.** A warning at the bottom of a long day or a tall bracket was only seen by someone who scrolled past
every game, which is least likely on game day. And two screens disagreeing about the same schedule makes both untrustworthy.

**Customer impact.** Organizers see the schedule's state where they land, at no cost in space when all is well. The
dashboard stops saying "No timed schedule" for playoffs-only tournaments.

**Priority.** The number fix shipped first (a bug on every tournament with playoffs). The button follows. The dashboard
opening the same window is the third step.

**Success looks like.** The Schedule and the dashboard always show one score. Nobody has to scroll to learn a schedule has a
clash. The health panel works the same from either place.

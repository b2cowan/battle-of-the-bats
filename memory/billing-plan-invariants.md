# Billing Plan Invariants

- Free Tournament has no trial period. When Platform Admin moves an org to the Tournament plan, billing state is normalized to `subscription_status = active` with no Stripe subscription id, subscription period, or current period end.
- Dev mock billing may still simulate paid-plan trial states, but Tournament + `trialing` is coerced to `active` so support screens do not show a free plan as trialing.
- Migration 050 normalizes existing rows where `plan_id = tournament` and `subscription_status = trialing`.
- The Founding Season is REMOVED from the product (offer closed 2026-10-26; code removed 2026-11-20, owner ruling 2026-11-19). Nothing applies a self-serve Tournament -> Tournament Plus upgrade in-app without Stripe any more: that upgrade goes through Stripe checkout at list price, and no code can grant, extend or end a Founding comp. The three former holders (two clubs, one coach portal) carry ordinary staff-given free time through September 30, 2027 (migration 510, owner-run on production): a club holder is stored on `plan_id = tournament` with a running Tournament Plus free-time grant over it, and the coach's portal is a free-time `platform_override` entitlement. `org_overrides.type = comp_period` survives only as an old-row value (its CHECK value stays); no live code writes it and the holders' marks are revoked.
